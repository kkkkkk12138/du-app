# 渡 Google Play 数据安全填写草稿

这份草稿依据当前本地优先实现编写。提交 Play Console 前必须用最终 Release 包、依赖清单和实际网络请求复核。

## 当前数据边界

| 项目             | 当前实现                                                 |
| ---------------- | -------------------------------------------------------- |
| 账号             | 不提供注册或登录                                         |
| 文字与结构化记录 | 保存在本机 WatermelonDB                                  |
| 照片、录音和手书 | 保存在应用本地目录                                       |
| 地点             | 用户主动添加后保存在本机                                 |
| 完整备份         | 用户主动导出到自己选择的位置                             |
| 数据恢复         | 用户主动选择本地备份文件                                 |
| 广告             | 不包含                                                   |
| 云同步           | 不包含                                                   |
| 数据销售         | 不进行                                                   |
| 数据删除         | 用户可删除单条内容；完整清除可通过系统清除应用数据或卸载 |

## Play Console 初始答案

### 应用是否收集或分享所需的任何用户数据类型

若最终 Release 没有向开发者或第三方服务器发送用户数据，可选择“不收集或分享”。系统权限、本机处理和用户主动导出到自己选择的位置，通常不等于开发者收集数据。

### 数据是否在传输过程中加密

当前核心数据不上传服务器，当前版本也不包含第三方崩溃采集或分析 SDK。

### 是否提供数据删除请求机制

当前没有账号和服务器端数据。用户可以在应用内删除内容，也可以通过 Android 系统清除全部本地数据。若问卷要求提供外部删除请求 URL，应根据“没有服务器端账号数据”的选项填写，不能虚构接口。

## 权限与用途

| 权限或系统能力 | 用途                     | 触发方式           |
| -------------- | ------------------------ | ------------------ |
| 相机           | 拍摄日迹或信件附件       | 用户点击拍照       |
| 麦克风         | 录制音频附件             | 用户点击录音       |
| 粗略/精确位置  | 给当前记录添加地点       | 用户点击定位       |
| 通知           | 每日提醒和未来信到达提醒 | 用户启用提醒       |
| 生物识别       | 解锁本机内容             | 用户启用隐私锁     |
| 系统照片选择器 | 选择照片或书籍封面       | 用户点击从相册选择 |
| 系统文档选择器 | 选择备份文件             | 用户点击恢复       |
| FileProvider   | 分享用户主动导出的文件   | 用户点击导出       |

应用不声明读取整个相册的权限，也不声明旧版外部存储读写权限。

## 发布前复核

逐项检查最终 `AndroidManifest.xml`、Gradle 依赖和真机网络请求。新增登录、同步、诊断、分析、广告、客服 SDK、推送服务或云存储后，这份草稿必须重写相应部分。
