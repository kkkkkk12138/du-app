## 网络资源说明

`du-legal` GitHub Pages 用于公开展示政策，不等于中国大陆网络接入资源备案。若接入商或应用商店要求境内域名、IP 地址或服务器，应购买本人长期持有的域名和中国大陆地域云资源，再把政策页面迁移到该域名。

当前版本没有自建业务后端。向接入商说明时使用以下表述：

> 渡 1.0.1 是本地优先的个人记录工具。用户创建的文字、照片、录音、手书、地点、信件和备份默认仅保存在用户设备或由用户主动选择的文件位置。应用不提供注册登录、云同步、广告、统计分析或自建服务器上传功能。网络权限用于系统网络状态与系统服务兼容，不上传用户日记正文和附件。

不要填写虚构的服务器 IP、域名或云服务商。接入商若判定当前形态仍需境内网络资源，应先购买并完成网站/域名备案，再提交 APP 备案。

## 权限用途

| 权限 | 备案用途说明 |
| --- | --- |
| 相机 | 用户主动拍摄日迹、信件或书籍封面 |
| 麦克风 | 用户主动录制音频附件 |
| 精确/大致位置 | 用户主动为记录添加地点并生成城市归类 |
| 通知 | 每日提醒和未来信到达提醒 |
| 生物识别 | 使用系统面容或指纹解锁本机隐私内容 |
| 旧版存储权限 | 仅 Android 8/9 保存用户主动导出的图片 |
| 网络状态 | 判断设备网络状态和系统服务兼容，不读取网络内容 |
| 唤醒与开机完成 | 恢复用户设置的本地提醒 |

相机、麦克风、位置、通知和生物识别均在用户触发对应功能时申请。拒绝后不影响无关功能。

## 提交流程

1. 选择支持个人 APP 备案的网络接入服务商或目标应用分发平台。
2. 使用本人证件注册并完成实名认证。
3. 在服务商备案入口选择“APP 备案”或“移动应用备案”。
4. 填写本文件中的应用名称、包名、版本、服务内容和签名指纹。
5. 按服务商实际要求填写域名、IP 地址或网络接入信息；没有真实资源时不要编造。
6. 上传服务商要求的证件、承诺书、隐私政策和 APK 信息。
7. 由本人完成人脸核验、短信核验和电子签署。
8. 等待接入商初审与省级通信管理局审核。
9. 取得备案编号后，将编号回填到本文件、公开政策页、App“关于渡”和各商店后台。
10. 在 App 显著位置展示备案编号，并链接至 `https://beian.miit.gov.cn/`。
