# 渡个人时光记录软件 V1.0 用户操作手册

文档版本：1.0

适用软件：渡个人时光记录软件 V1.0

运行平台：Android、iOS

## 软件概述

渡用于记录日常片段、未来信和与地点有关的个人记忆。软件采用本地优先的数据处理方式，文字、照片、录音、手书、地点、信件和个人资料默认保存在设备本地。

软件由日迹、信、落笔、远方和个人资料五个主要入口组成。日迹用于按时间浏览记录；信用于管理未来信；落笔用于创建内容；远方用于按城市、念想和副本重新组织内容；个人资料用于管理书架、散页、提醒、隐私和备份。

当前版本不要求注册账号，也不提供云同步。卸载软件、清除应用数据或设备故障可能造成内容丢失。用户应在执行这些操作前导出完整备份。

## 安装和首次启动

### 安装软件

1. 从应用商店下载“渡”。
2. 等待系统完成安装。
3. 在设备桌面找到红色印章样式的“渡”图标。
4. 点击图标启动软件。

软件首次启动时展示产品介绍与隐私说明。软件不会在用户同意隐私政策前主动申请相机、麦克风、位置、通知或生物识别权限。

### 完成首次引导

1. 阅读各页产品介绍。
2. 在最后一页点击《隐私政策》。
3. 阅读数据处理、权限用途、数据保存和删除说明。
4. 返回引导页。
5. 点击“同意隐私政策并开始”。

完成后进入日迹首页。首次安装会写入可删除的示例内容，用于说明日迹、信件、念想、副本、书架和散页的操作方式。

## 创建日迹

### 输入文字

1. 点击底部中间的“落笔”。
2. 在正文区域输入文字。
3. 输入框支持中文、英文、数字和常用符号。
4. 内容会保存在当前草稿中。

### 添加地点

1. 在落笔页点击地点入口。
2. 选择自动定位或手动输入。
3. 自动定位时按系统提示允许位置权限。
4. 手动输入时可填写城市、街道、景点或私人地点。
5. 等待软件识别行政区信息。
6. 确认显示的地点后返回正文。

软件会尽量把中国区县和县级市归入上级地级市，把直辖市辖区归入直辖市。窗台、工位等私人描述可以保存在记录中，但不会被错误计入城市统计。

### 添加照片

1. 点击照片入口。
2. 选择“拍照”或“从相册选择”。
3. 拍照时允许相机权限。
4. 从相册选择时使用系统照片选择器。
5. 确认照片后返回落笔页。

照片保存在应用沙盒中。删除包含照片的记录时，软件会同步清理对应附件。

### 添加录音

1. 点击录音入口。
2. 按系统提示允许麦克风权限。
3. 点击开始录音。
4. 说完后点击停止。
5. 在落笔页播放录音，确认内容正常。

### 添加手书

1. 点击手书入口。
2. 在画布中书写或绘制。
3. 使用撤销、清除等工具调整内容。
4. 点击完成，将手书加入当前记录。

### 保存日迹

1. 确认正文和附件。
2. 选择保存为普通日迹。
3. 点击完成。
4. 返回日迹首页查看新记录。

## 创建未来信

### 设置到达时间

1. 在落笔页完成正文和附件。
2. 选择“寄给未来”。
3. 在同一时间选择器中设置年、月、日、时、分。
4. 到达时间必须晚于当前时间。
5. 确认时间并保存。

未来信保存在本机数据库中。到达提醒依赖系统时间、通知权限和系统调度能力，卸载软件或清除数据会删除尚未到达的信件。

### 查看信件状态

1. 点击底部“信”。
2. 查看在途、将至、已到达或已拆信件。
3. 点击信件查看详情。
4. 已到达信件会显示红色印章拆信入口。

### 拆开未来信

1. 打开已到达信件。
2. 点击红色印章。
3. 等待信纸从信封中抽出。
4. 阅读正文和附件。
5. 使用“收回”返回信箱。

## 浏览和管理日迹

### 查看详情

1. 在日迹首页上下滑动。
2. 点击任一记录。
3. 在全屏信纸中查看正文、照片、录音、手书和地点。
4. 点击页面下方的次级操作区执行复制、存为图片或删除。

### 保存内容图片

1. 打开记录详情。
2. 点击“存为图片”。
3. 按系统提示允许添加照片或旧版存储权限。
4. 等待图片浮起提示。
5. 在系统相册的“渡”相册中查看结果。

导出图片只包含记录内容和必要元数据，不包含导航栏、按钮和空白回信区域。

### 删除内容

1. 打开需要删除的记录或信件。
2. 点击删除。
3. 阅读删除影响。
4. 确认删除。

删除后，对应城市、念想、副本和个人统计会重新计算。某个城市的最后一条关联内容被删除后，该城市不再显示在足迹中。

## 使用远方

### 查看城市足迹

1. 点击底部“远方”。
2. 进入足迹区域。
3. 查看出现过有效城市信息的城市卡片。
4. 点击城市打开详情浮层。
5. 上下拖动浮层调整高度。
6. 点击其中一条记录跳转到对应详情页。

### 使用念想

1. 在远方页进入念想。
2. 新建念想并填写名称。
3. 将已有记录关联到念想节点。
4. 点击节点，在模糊背景前查看便利贴。
5. 完成的念想可使用小方框标记。
6. 不再需要的念想可删除。

### 使用副本

1. 在远方页进入副本。
2. 点击新建副本。
3. 输入中英文名称。
4. 选择上传封面或使用默认封面。
5. 在副本中添加节点。
6. 查看系统自动排布的手帐纸便利贴。
7. 删除不再需要的节点或整个副本。

## 使用书架

### 创建书籍

1. 打开“我”。
2. 点击“书架”。
3. 点击新建书籍。
4. 输入分类名称和书名。
5. 选择上传封面或使用默认封面。
6. 保存书籍。

### 阅读和续写

1. 点击一本书进入阅读器。
2. 左右翻页查看内容。
3. 点击续写。
4. 选择在当前页新增内容或开辟新页。
5. 新页可以设置眉头，也可以留空。
6. 保存后返回阅读器。

### 删除书籍

1. 在书架点击管理。
2. 选择需要删除的书。
3. 确认删除整本书及其页面。

空白书籍会显示空状态和续写入口，不会伪造页面内容。

## 使用散页

1. 打开“我”。
2. 点击“散页”。
3. 查看系统自动避让放置的卡片。
4. 长按并拖动卡片进行自由排版。
5. 点击“拢齐”恢复紧凑排列。
6. 将卡片拖入废纸篓，或在管理模式删除。
7. 误删后在提示有效时间内点击撤销。

拖动卡片只改变画布中的位置，不应带动整个页面抖动或意外滚动。

## 管理个人资料

1. 打开“我”。
2. 点击头像或编辑入口。
3. 从相册选择头像。
4. 修改昵称。
5. 按需填写生日等个人字段。
6. 保存修改。

头像、昵称和生日默认保存在本机。

## 设置提醒

### 每日提醒

1. 打开“我”中的提醒设置。
2. 开启每日提醒。
3. 选择提醒时间。
4. 按系统提示允许通知权限。
5. 返回后确认开关与时间已保存。

### 信件到达提醒

1. 打开信件提醒设置。
2. 开启信件靠岸提醒。
3. 允许通知权限。
4. 保持设备时间和时区正确。

部分 Android 系统会限制后台调度。提醒延迟不影响软件下次启动时根据当前时间重新核对信件状态。

## 隐私锁

1. 打开“我”中的隐私设置。
2. 开启生物识别锁。
3. 按系统提示验证面容或指纹。
4. 退出并重新进入软件验证锁定效果。

软件只接收系统返回的验证成功或失败结果，无法读取面容或指纹模板。

## 导出和恢复

### 导出完整备份

1. 打开“我 > 关于渡 > 数据与隐私”。
2. 点击导出完整备份。
3. 阅读备份包含的数据类型。
4. 选择可信的本地或云盘位置。
5. 等待系统完成保存。

完整备份可能包含私人文字、照片、录音、手书、位置和个人资料，不应公开发送或上传到不可信位置。

### 恢复完整备份

1. 打开“我 > 关于渡 > 数据与隐私”。
2. 点击恢复完整备份。
3. 选择由渡导出的 `.du-backup.json` 文件。
4. 查看版本、记录数和附件摘要。
5. 确认恢复。
6. 等待软件校验文件并写入数据。
7. 返回各页面核对内容。

恢复会替换当前设备中的渡数据。软件会尝试先创建救援备份，并在写入失败时回滚。

## 权限管理

相机、麦克风、位置、通知、生物识别和照片权限均用于对应功能。用户拒绝某项权限后，仍可使用其他功能。

在 Android 中，可打开“设置 > 应用 > 渡 > 权限”修改授权。在 iOS 中，可打开“设置 > 渡”修改授权。

## 故障处理

### 无法输入中文

1. 确认系统已安装并启用中文输入法。
2. 点击输入框后手动切换输入法。
3. 完全退出软件并重新打开。
4. 若仍异常，记录设备型号、系统版本和输入法名称。

### 城市未进入足迹

1. 确认记录仍存在且未被删除。
2. 检查地点是否为可识别城市、区县、街道或景点。
3. 私人地点描述不会计入城市。
4. 重新打开软件，等待历史地点回填。

### 无法保存图片

1. 检查设备剩余空间。
2. 检查照片或旧版存储权限。
3. Android 10 及以上通常不需要传统存储权限。
4. Android 8/9 需要允许旧版相册写入权限。

### 通知没有出现

1. 检查系统通知权限。
2. 检查软件内提醒开关。
3. 检查系统时间和时区。
4. 检查厂商系统的电池优化和后台限制。

### 数据丢失

1. 不要继续大量创建新内容。
2. 打开数据与隐私页面，检查是否存在可恢复备份。
3. 从本人保存的完整备份执行恢复。
4. 当前版本没有账号云端副本，无法从运营者服务器找回本机未备份内容。

## 数据删除

普通内容、信件、念想、副本、书籍和散页均提供应用内删除入口。卸载软件或在系统设置中清除应用数据会删除本机内容。

由用户导出到相册、文件应用、云盘或其他第三方位置的副本，需要用户到对应位置自行删除。渡无法访问或删除这些第三方副本。
