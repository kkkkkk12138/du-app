## 软件功能说明

渡是一款本地优先的个人时光记录应用。用户可以记录文字、照片、录音、手书和地点，将内容保存为日迹或设置为未来信。应用根据记录关联的行政区信息生成城市足迹，并提供念想、副本、书架和散页等整理方式。

应用使用 WatermelonDB 管理结构化数据，通过应用沙盒保存附件。未来信和每日提醒使用系统本地通知；地点功能使用系统定位与地理编码。当前版本不提供账号登录、云同步、广告、统计分析或第三方崩溃采集。

## 功能模块

1. 日迹：创建、查看、编辑关联信息、删除和导出日常记录。
2. 未来信：设置年、月、日、时、分，在本地保存并按时间解锁。
3. 信箱：展示在途、将至、已到达和已拆信件。
4. 远方：按城市聚合记录，展示足迹、念想和副本。
5. 书架：创建分类和书籍，续写页面并管理封面与内容。
6. 散页：自动放置和自由拖拽卡片，支持拢齐、删除和撤销。
7. 多媒体：拍照、选择照片、录音、播放录音和手书。
8. 隐私：生物识别锁、本地删除、完整备份、恢复和数据说明。
9. 提醒：每日记录提醒和未来信到达提醒。

## 鉴别材料

中国版权保护中心的一般交存要求是：

- 源程序前、后各连续 30 页；不足 60 页时提交全部源程序。
- 程序通常每页不少于 50 行。
- 任一种软件文档前、后各连续 30 页；不足 60 页时提交全文。
- 文档通常每页不少于 30 行。
- 申请表、源程序页眉和文档页眉中的软件名称、版本号必须一致。

生成源程序文本：

```sh
bash scripts/generate-software-copyright-source.sh
```

默认输出：

```text
build/software-copyright/渡软件V1.0源程序鉴别材料.txt
build/software-copyright/source-files.txt
```

生成器仅收集 Git 跟踪的第一方源文件，不包含 `node_modules`、构建产物、签名文件、密码、用户数据库或真实备份。

文档鉴别材料使用：

```text
docs/android-cn/SOFTWARE_USER_MANUAL.md
```

提交前将源程序和用户手册分别转为纵向 PDF。源程序采用等宽字体并固定每页 50 行；用户手册固定每页至少 30 行。页眉统一写“渡个人时光记录软件 V1.0”并连续编号。

## 本人准备的证明

1. 在中国版权保护中心官网注册个人账号并完成实名认证。
2. 在线填写申请表并核对本文件中的预填字段。
3. 下载系统生成的申请确认签章页。
4. 按原比例打印，由著作权人签字后扫描为 PDF。
5. 上传本人身份证明；证件文件仅进入官方系统。
6. 上传源程序鉴别材料 PDF。
7. 上传用户手册鉴别材料 PDF。
8. 若软件属于任职期间职务开发、合作开发、委托开发或使用了他方未公开资源，应先确认真实权属并补充相应合同或证明，不能按个人独立开发直接申报。

## 官方办理路径

1. 打开中国版权保护中心官网：`https://www.ccopyright.com.cn/`。
2. 进入著作权登记系统，注册并完成实名认证。
3. 选择计算机软件著作权登记申请。
4. 在线填报并上传 PDF 材料。
5. 提交后在用户中心查看受理与补正通知。
6. 收到补正通知时，在通知发出之日起 30 日内按原申请口径补正。
7. 审查完成后，在用户中心下载软件版权登记电子证书。
